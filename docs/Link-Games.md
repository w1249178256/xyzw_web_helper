# 在线游戏

入口位于顶部导航「主线推关」后，地址为 `/admin/Link-Games`。移动端可从侧栏进入。

从本地 Token 列表选择账号即可开启独立游戏窗口，支持静音、窗口尺寸、FPS、倍速、自适应排列、聚焦、重登和关闭。切换到其他页面会保留窗口，刷新或关闭浏览器页面会停止游戏；删除账号也会关闭对应窗口。

同一浏览器的标签页通过 Web Locks（可用时）和本地占用记录协调角色使用。在线游戏运行期间，助手会停止并阻止该账号的自动连接。此协调不涉及其他设备。

## 资源代理

此功能使用本地 Token，不依赖 FE_Sqlite 后端。游戏版本信息与启动脚本由当前部署的 `/api/link-games/` 代理访问固定游戏域名。

- 开发与预览：Vite 内置中间件。更新配置后需要重启原有的 `pnpm run dev` 进程。
- Cloudflare Pages：随现有 `worker.js` 部署。
- EdgeOne Pages：由 `edge-functions/api/link-games/[[default]].js` 处理。
- Docker：使用仓库的 `docker/nginx.conf`。
- 其他静态托管：需要配置对应资源代理；仅上传静态文件不能处理游戏版本接口。页面会提示代理不可用。

代理仅允许游戏版本接口和固定公共资源域名，账号 Token 通过同源消息传给对应的游戏窗口，不放入 iframe URL，也不发送给资源代理。

## 验证

`node --test test/linkGames.test.js` 可离线检查账号解析、占用协调、代理转发限制、窗口取消和连接互斥。实际游戏画面、网络登录和声音需要在浏览器中测试。
